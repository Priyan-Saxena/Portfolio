# Portfolio

# 🧪 Digital Sandbox — Priyan Saxena

An experimental personal portfolio that trades the usual template layout for a **terminal boot sequence**, a **live Three.js background**, and **scroll-driven storytelling**. Built to showcase identity, projects, hackathons, and interests in an interactive, unconventional format.

> Built by [Priyan Saxena](https://github.com/Priyan-Saxena) — 2nd year Computer Science student at JIIT 128, Developer, Designer, AWS Campus Ambassador, and AI enthusiast.

---

## 📖 About

This site intentionally breaks conventional portfolio rules. Instead of a static hero section, visitors are greeted with a typewriter-style terminal boot sequence before entering a fully interactive experience powered by WebGL, scroll animations, and custom UI interactions.

---

## ✨ Features

- **Terminal-style boot sequence** with typewriter effect
- **Interactive 3D wireframe + particle field** (Three.js)
- **GSAP + ScrollTrigger animations** with animated number counters
- **Tilt-on-hover lab cards** for an added layer of interactivity
- **Custom noise overlay** paired with mono/display typography
- **Fully responsive** across devices

## 🚀 Run Locally

Open `index.html` directly in a modern browser (**Chrome / Firefox / Edge** recommended for WebGL support), or serve it locally:

```bash
npx serve .
```
